# Сайт юриста

Одностраничный сайт судебного юриста: поддержка и защита при клевете, оскорблениях и травле, ситуации, результаты, отзывы, экспертиза, заявка с уведомлением в Telegram и юридический подвал. Без сборки и фреймворков — обычные HTML и CSS, поэтому его просто хостить и просто править.

**Статус: черновик.** Тексты и контакты — заглушки (подсвечены жёлтым), сайт закрыт от поисковиков.

## Как устроено

- Вся страница — `index.html`, стили — `css/style.css`, скрипты — `js/site.js`, приём заявок — `functions/api/lead.js`.
- Правила для ИИ-ассистента (Codex) и типовые задачи — в [`AGENTS.md`](AGENTS.md).
- Проверка перед публикацией: `python3 tools/check.py` (ссылки, якоря, оставшиеся заглушки).

## Посмотреть у себя на компьютере

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000.

## Публикация

Сайт — просто набор файлов, его можно положить на любой хостинг. Для временной ссылки подходит бесплатный хостинг с подключением к GitHub: каждая правка в `main` публикуется автоматически, а у каждого pull request есть своё превью.

## Как вносить правки

Через pull request: правка → превью → проверка → Merge. Напрямую в `main` не коммитим (см. `AGENTS.md`).
