# Сайт юриста

Статичный сайт судебного юриста: главная, ситуации, обо мне, экспертиза, блог, форма записи с уведомлением в Telegram. Без сборки и фреймворков — обычные HTML и CSS, поэтому его просто хостить и просто править.

**Статус: черновик.** Тексты и контакты — заглушки (подсвечены жёлтым), сайт закрыт от поисковиков.

## Как устроено

- Страницы лежат в корне и в `blog/`, стили — в `css/style.css`, скрипты — в `js/`, приём заявок — в `functions/api/lead.js`.
- Правила для ИИ-ассистента (Codex) и типовые задачи — в [`AGENTS.md`](AGENTS.md).
- Проверка перед публикацией: `python3 tools/check.py` (ссылки, единая шапка и подвал, оставшиеся заглушки).

## Посмотреть у себя на компьютере

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000.

## Публикация

Сайт — просто набор файлов, его можно положить на любой хостинг. Для временной ссылки подходит бесплатный хостинг с подключением к GitHub: каждая правка в `main` публикуется автоматически, а у каждого pull request есть своё превью.

## Как вносить правки

Через pull request: правка → превью → проверка → Merge. Напрямую в `main` не коммитим (см. `AGENTS.md`).
